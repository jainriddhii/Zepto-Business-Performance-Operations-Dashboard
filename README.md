# Zepto Business Performance & Operations Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyse Zepto's business performance across sales, customers, products and operations.

The dashboard brings key business metrics into a single view to help identify trends and performance drivers across different business dimensions.

## 🎯 Objectives

- Track overall business performance using key KPIs
- Analyse revenue and Average Order Value (AOV)
- Understand customer activity and membership behaviour
- Compare performance across cities
- Analyse product category performance
- Evaluate delivery and operational performance

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Cleaning & Transformation
- Data Modelling

## 📈 Key KPIs

- Total Revenue
- Average Order Value
- Customer Activity
- Delivery Performance
- Sales Performance

## 🔍 Analysis

The dashboard analyses business performance across:

- **Cities** – identifying geographical performance trends
- **Membership Tiers** – comparing customer behaviour across membership levels
- **Product Categories** – understanding category-wise performance
- **Sales Trends** – analysing revenue and order patterns
- **Operations** – evaluating delivery performance
